# AI/LLM Integration & SEO. 2.7.1 is the network floor as of the floor round.
# 2.5.1 was the Tier-B SEO standard (per-page title/image/schema type reach
# the crawler document; the prerender no longer clobbers the browser's
# per-page <title>); 2.6.0 adds the honesty standard on top: sitemap
# <lastmod> is emitted verbatim from register_page_metadata(lastmod=) and
# OMITTED when unset, instead of being swallowed into **kwargs while the
# sitemap swears every page changed at build time. Also 2.6.0: icon
# AUTODISCOVERY over app assets — which is why this repo's favicon pixels
# had to land first (the ordering rule: discovery would otherwise cement
# whatever art it found), JSON-LD publisher.logo, and viewer banner de-dup.
# The [flask] extra pins the bot-middleware deps for this site's backend.
# NOTE: dimll pins dash<5,>=4.1 — this is what makes the SITE's Dash floor
# higher than the package's.
#
# 2.6.1 made the prerender LOAD-BEARING here: below it the injected div
# carries a literal `hidden` attribute, so every visibility-respecting
# consumer — html-to-text extractors, arguably crawler content weighting —
# read "Loading..." and nothing else. This site removed its hand-written
# <noscript> block in the same deploy that brought 2.6.1, precisely so no
# window exists where a non-JS reader has neither.
#
# 2.7.0 then dedups what that visible block SAYS: one H1 per page instead
# of the injected header plus the doc body's own (a duplicate-H1 page in
# every crawler's eyes), the home footer's doubled /llms.txt link, and a
# hardened idempotency probe. 2.7.1 adds the llms.txt v2 discovery
# relations + Link headers, the text/plain Accept ramp, and the
# representation digest.
