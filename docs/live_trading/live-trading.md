### Overview

`LiveTradingChart` is the real-time streaming chart component of
dash-mui-charts, built for live data visualization such as trading feeds
and sensor streams. The demo renders a live OHLCV candlestick simulation
with volume bars, a forecast line with uncertainty bands, and alert labels
on significant moves — ticks are generated by the component itself from a
seed, so no Dash interval is needed to stream.

Basic streaming is Community tier. Pro features — zoom and the range
slider (`showSlider`) — require a MUI X Pro license key passed as
`licenseKey` (read here from `MUI_PRO_API_KEY`).

Simulation props are live-updatable from Dash callbacks: `running`,
`intervalMs`, `volatility`, `drift`, `windowSize`, `seed`,
`forecastVolatility`, and `resetTrigger` (change its value to restart).
Output props updated as the simulation runs: `currentPrice`, `tickCount`,
and `alertHistory`.

.. admonition::Functions-as-props
    :icon: mdi:function-variant
    :color: blue

    `alertFormatter` and `alertFilter` accept
    `{'function': 'name', 'options': {...}}`, resolved from the
    `window.dashMuiChartsFunctions` registry defined in
    `assets/muiChartsFunctions.js` — the demo formats prices with
    `priceAlertFormatter`.

---

### Live simulation

Start the simulation, then drive it: speed, volatility, drift and window
size are sliders; volume bars, price labels and the zoom preview are
toggles. The stats row and alert log stream from the chart's output props.
